# 产品渲染经验：以已确认画面为准（2026-11-08）

适用：产品棚拍、鼠标/电子产品、内部爆炸图、材质真实感与产品动画。普通建模、查看场景等任务不执行本流程。用户本轮要求、已确认的画面和授权范围优先；本指南是经验，不是固定审美或必须反复询问的审批规则。

## 先看参考与模型，再做画面

- 读取实际参考像素，拆解相机高度/透视、爆炸方向、主体占比、零件注册关系、背景深度、主光方向、阴影、反射形状和各部件材质。只拿到路径不等于看过图。不要把 AI 概念图里的错误结构、图案、文字一起做进模型。
- 检查现有模型的网格、法线、厚度、装配尺度与内部资产。保留用户外形；缺失内部按实际产品资料补充。不能靠摆几块方片就宣称 OEM 内部还原；示意建模须说明边界。
- 把“轻盈”落实为薄壳、真实厚度、适量组件、受控间距、悬浮平台与离地阴影，而不是任意拉散零件。保留产品轮廓和装配关系，构图先于堆细节。

## 材质真实感必须来自材质响应

- 先按实际部件建立材质表：硬壳、细磨砂侧键、低反射橡胶侧裙、粗颗粒轮胎、刚性中框、涂覆 PCB、IC 环氧与金属触点分别处理。不能给所有黑色部件套同一种塑料。
- 表面颗粒主要进入法线/凹凸和窄幅粗糙度变化；用实际物体尺度决定频率与微米级高度。近景能分辨工艺，远景仍保持干净的形体和材质层次。不要把提高噪声强度当作真实感。
- 不用 Base Color 的大块 Noise/Voronoi、贴花或随机碎片冒充磨砂、橡胶或碳纤维。仅当产品明确需要可见纹样时添加图案；碳纤维应有合理纤维尺度、方向与反射，不能用迷彩色斑代替。
- 出现蜡感时，联查法线/细分是否过圆、反射光源是否过宽、粗糙度分布是否过散、填光是否过强，以及 Coat/SSS/Transmission 是否误开。不要只增加颗粒或盲目提高粗糙度。普通不透明塑料通常无需 SSS/Transmission，金属度应为零。
- 使用同一材质同时看整体、局部原尺寸裁切与缩略图：近景粗糙不代表远景就摆脱蜡感。以真实参考的高光过渡和暗部质感判断，不以节点数量判断。

## 摄影布光与场景

- 先用一个有方向、有形状的主光塑造明暗，再加受控的窄轮廓光、弱回光和必要的材质掠射光。面积、角度、距离决定反射形状；避免所有方向的大软光把产品照成均匀发亮的蜡块。
- 深色部件要有可读的暗部层次与边缘分离，避免全黑。橙色等饱和硬壳保留颜色和明暗过渡，避免大片白色反光抹掉涂层。强明暗不等于整体欠曝或金属过曝。
- 背景、台面、地面应有深度、接触/离地阴影和连续过渡；暗棚可用克制的聚光渐变与薄平台。不要用几根发光线替代场景，也不要用浓雾遮盖材质问题。高科技感不等于遍地霓虹和杂乱配色。
- 色彩管理、曝光与构图在预览确认后保持一致；不要高分辨率阶段偷偷换背景、光位或材质。

## 爆炸结构与检查

- 用空物体管理底壳、PCB、机械/供电组件、中框侧裙、上盖等装配层。沿共同装配轴拆开；保留局部坐标和原始尺寸。不要误用旧爆炸父级的世界变换，造成零件错位或重复变换。
- 微动、焊点、电子元件留在所属板件上；轴承、滚轮、电池座与触点维持合理关系。不要把每个螺丝都任意抛散，也不要让外壳遮住所有内部。
- 检查相机裁切、投影遮挡、层间净距与明显穿模。BVH/包围盒只能辅助，不等于视觉验收；同层的装配接触和层间碰撞应分别判断。电池、接口、滚轮结构必须符合所用产品，不能照抄另一款产品或 AI 图。

## 收敛流程与授权

- 先在副本/独立场景完成构图与真实材质小样；用实际相机低分辨率渲染检查，不能把脚本成功或视口截图当最终成图。
- 一轮集中解决一个明确问题：先装配和构图，再按部件处理材质，再调布光。对照同一视角，保留已确认的改动；不要每轮推翻整个场景，也不要只微调同一个错误方案。
- 输出小样前 Agent 自己看真实图像，记录剩余可见问题并修正。只报告看过/检查过的内容；关闭图像输入的 Agent 不能宣称已目视核查。
- 用户要求“小样通过再出图/关键帧/动画”时，严格遵守相应阶段；动画还要检查关键帧与中间帧。用户已明确授权最终图或批准小样时，直接执行所需渲染，不再重复索要同一批准。未要求人工关口时，可内部自检后自主完成已授权交付。
- 最终保留已确认的构图、材质、布光，只提升分辨率、采样、降噪质量。另存 .blend 与原生 PNG，回读尺寸并检查成图和局部；不得把 AI 生成的概念图冒充 Blender 渲染。
