# JC Blender Agent 0.1.5

在 Blender 的 N 面板输入中文，选择 Codex / Claude Code / API Agent，通过 MCP 实际读写当前场景。运行时仅使用 Python 标准库和 Blender 原生 UI，不需要安装 Tk、pip、uv、Node 或第三方 Python 库。

## 安装与首次使用

1. 在 Blender：编辑 → 偏好设置 → 插件 → 右上角菜单 → 从磁盘安装，选择 `dist/JC-Blender-Agent-0.1.5.zip`。
2. 勾选 **JC Blender Agent**。在 3D 视图按 N，点 **JC Agent** 页签。
3. 点击 **连接 / 检查**。服务在本机回环地址启动，面板显示“已连接 Blender”。
4. 选择 Agent，填模型（本地 Agent 可留空沿用默认），输入要求，点击 **发送描述**。
5. 场景会实际改变；任务状态、简要回复在面板显示。完整回复和工具结果保存在文本块 `JC_Agent_Log` 与本地任务日志。
6. 可以继续描述修改，下一轮会带上上一轮任务与回复，再读取当前场景。

支持代码以 Blender 4.2+ 为最低版本；**本次实际验证版本为 Windows Blender 5.2.1 LTS**，其他版本尚未实机验证。

## 0.1.5：记住本机 API 配置

- “临时 API Key”改为“API Key”，默认勾选 **记住 API Key（仅本机）**。输入并提交字段后，自动按当前基础地址保存到 Windows 凭据管理器，重开 Blender 后留空即可自动使用；刷新模型列表和发送任务使用同一份保存的 Key。
- API 基础地址、协议、模型 ID、环境变量名及图像开关等非密钥设置保存在本机 `api-settings.json`，启动和打开项目时自动恢复。API 设置与 Key 均不随 `.blend` 保存。
- 切换 API 基础地址会清空当前输入，仅匹配新地址的凭据，不把旧地址的 Key 发给新服务。Key 留空不会删除保存值；旁边垃圾桶按钮仅清除当前地址的本机 Key。不勾选“记住”时只使用本轮输入或指定环境变量，不读取已保存值。
- Key 不写入明文配置、任务日志、发行包或经验库，不跨电脑自动迁移；新电脑首次使用需填写自己的 Key。目前系统凭据保存仅支持 Windows，其他系统仍可临时输入或使用环境变量。

## 0.1.4：内置产品渲染经验

- 将本次用户确认的 G603 橙黑爆炸图总结打包进插件：按部件区分材料、用微表面而非彩色图案表现颗粒、避免蜡感、摄影明暗、共同装配轴、连续背景与轻盈场景。
- 面板增加 **参考产品渲染经验库** 开关（默认开启，在插件偏好设置中记住选择）。开启时参考经验；关闭时自主调试，不注入经验、隐藏经验工具/资源并拒绝直接读取。它控制经验参考，不替代 Agent 自己观察参考图和场景的工作。
- Codex / Claude Code 与 API 的两种协议共用同一份指引；只有开启才随新任务自动带入，无需每次粘贴。外部 MCP 客户端按连接时的选择获取初始化指引，并可通过 `resources/list` / `resources/read` 获取资料。
- 完整案例包含失败原因、已采用的参数和尺度限制，以及实际成图的600×800预览。经验文件位于包内 `runtime/bridge/knowledge/`，按相对路径读取；**换电脑安装同一 ZIP 即可离线使用经验库**，不依赖原电脑工程、盘符或联网下载。不打包完整鼠标模型、原始高分辨率图、用户附件、凭据或历史日志。
- 仅对相关产品渲染任务适用；用户的新要求优先。小样通过再渲染等阶段按实际要求执行；已经批准成图时直接完成，不能重复索取批准。知识指引可以减少重复错误，不能保证所有 Agent 的审美和执行效果。
- 开关在发送时快照到本轮任务，运行中不改变既定模式；切换模式后不继承上一模式的自动回复历史。外部客户端已经读入的旧上下文无法撤回，切换后需新建连接/会话。换电脑的 Agent 登录/网关及新任务模型仍需按需配置。
- 完整工程保留在本机原项目。更新安装后重新启用插件或重启 Blender 载入新运行时，不会强制关闭未保存场景。

## 0.1.3：本地附件路径引用

- 要求框下方的“添加附件”打开原生文件选择器，可多选。Windows 下也可在资源管理器复制文件，再点“粘贴文件”。这两个按钮只添加本地绝对路径，原文件不会复制到插件或运行目录。
- 附件列表显示文件名和路径检查状态；鼠标停留显示路径。“×”只移除本轮引用，不删除原文件。附件路径不保存进 .blend。
- 发送时记录本轮所选附件，交给当前 Agent。Agent 通过新增的 blender_attachment MCP 工具按需读取，不能读取未加入当前任务的附件 ID。读取附件不计作已操作 Blender。
- 图片：PNG/JPEG/WebP 小图直接按需读取实际像素；其他图片或大图由独立后台 Blender 转成预览。文本：按需读取，最多 64000 字，超出明确标注截断。
- 视频：添加时不解码、不复制；Agent 第一次请求画面时，另起独立后台 Blender 均匀提取参考帧。默认 8 帧，在文件选择器中可设 1–24 帧；采样有时间点，**不是完整观看，不含音频或转录**。不改当前 Blender 布局或场景。
- 模型、.blend、PDF 及其他格式：提供路径及文件信息；本版不解析 PDF 正文，不自动导入模型、不执行附件脚本。Agent 可按用户要求通过 Blender Python 导入模型。移走、删除或修改原文件后需要重新添加引用。
- API 模式的图片/视频需要开启“模型支持图像输入”，并选择支持图像的模型。按需读出的文本/图像会发送给当前 Agent/模型服务商；原始视频不会整段上传。

## 0.1.2：保留原生外观，同时显示 Agent 与历史

- **原生面板共存**：点击面板底部“与历史等工具同时显示”，固定 Agent 后恢复之前的 N 面板页签。之后切到 JC历史等工具，Agent 仍显示，两个面板可同时展开、点击与操作。也可在标题上右键 → 固定面板，或 Shift+点击标题；取消固定同样用 Blender 原生操作。
- **原生浮层入口**：3D 视图上方的 Agent 按钮打开相同样式的原生浮层。它是临时弹出层，点击其他区域会关闭；需要与历史长期共存时使用固定面板。
- **模型列表点选**：连接或更改 Agent / API 地址 / Key 后自动获取；点击列表行填入模型 ID。可手动刷新，也保留自填 ID。
- **Codex**：调用本机 codex debug models，显示该客户端返回的模型目录；目录可能含缓存，不代表核验过每个模型的账号额度。
- **API**：请求基础地址下的 GET /models。网络等待在独立服务进行，不阻塞 Blender；获取失败时显示错误并保留手填能力。
- **Claude Code**：显示官方模型别名并标明来源，不伪称为账号实时可用清单。
- **原生多行要求框（Blender 5.2+）**：直接输入中文、粘贴多行，Shift+Enter 换行；拖动输入框右下角缩放柄拉高。点击“发送描述”发送完整要求。较旧 Blender 保留单行和从文本块发送长描述的方式。

更新安装后需重新启用插件或重启 Blender 以载入新代码。首次连接会在旧版服务没有活动任务时更新该服务；仍有任务则先提示结束任务，保留原任务执行。

## 选择本地 Agent

### Codex

先在本机安装并登录原生 Codex CLI。插件能自动发现 PATH 和 Codex Desktop 自带的 `codex.exe`；也可在插件偏好设置填写路径。使用当前账号、服务商与模型配置，不读取、复制或导出登录凭据。

“模型”留空时沿用本机默认。若默认是图像模型（例如本次机器上的 `gpt-image-2`），应改填账号实际支持的文本 Agent 模型。本次真实联调用的是本机模型目录中存在的 `gpt-6.1-sol`；这不代表其他账号均可使用该 ID。

启动方式为 `codex exec --json`，仅在本次进程注入 `jc_blender` MCP 配置。针对这一个服务允许执行工具；shell 保持 read-only。不会修改全局 Codex MCP 配置。

### Claude Code

需要已安装并登录的原生 `claude.exe`。插件提供 Claude Code CLI 适配器，采用 `-p --mcp-config --strict-mcp-config`，只允许 `mcp__jc_blender__*` 工具。CLI 可执行文件路径可在插件设置指定。**本机未安装 Claude CLI，此适配器尚未通过真实账号联调。**

本版不启动 `.cmd` / `.bat` / `.ps1` 包装脚本，避免把用户文本拼接成 shell 命令。请使用原生 CLI 可执行文件。

## 选择 API Agent

面板填入：

- 基础地址：例如服务商提供的 `https://供应商域名/v1`；不要重复填写 `/chat/completions` 或 `/responses`。
- 协议：Chat Completions 或 Responses，必须与实际网关兼容。
- 模型 ID：服务商实际开放、支持工具调用的模型。
- Key：填写“API Key”，默认记住在本机；也可取消记住仅本轮输入，或指定已配置的环境变量名。环境变量需要在 Blender 启动前设置。
- 图像输入：模型支持图像时勾选，Agent 才能看见实际截图；纯文本模型取消勾选。
- 最多推理轮数：默认 24，每轮可能调用多个工具；到达上限会停止并说明。

Key 不进入任务 JSON、MCP 命令参数或 `.blend`；记住时仅交给 Windows 凭据管理器保存。重启读取、按地址隔离、清除以及 `.blend` 保存/重开使用测试哨兵验证。任务文本、对象名和截图会发送到你所选的 Agent / API 服务商，具体计费和数据政策遵循该服务商。

远程 API 地址要求 HTTPS；`localhost`、`127.0.0.1` 可用 HTTP，支持相同工具协议的本机模型。远程 API 跳转会被拒绝，应直接配置最终基础地址。不会自动扫描 Key 或读取其他项目中的凭据。

API 模式不是只生成脚本：内置的工具循环启动真实 MCP stdio 子进程，完成“模型工具调用 → MCP → 当前 Blender → 返回结果/图像 → 再推理”。两种协议已用模拟 API 测试，包括图像回传；**尚未用用户真实 API Key / 网关进行在线验证**。

## 输入长描述

在“要求”框输入描述。Blender 5.2+ 支持 Shift+Enter 换行、粘贴多行，拖动框右下角的缩放柄调高度。也保留从已有 Blender 文本块发送的方式。

发送时记录场景、活动对象、选择对象、时间轴帧和 Blender 版本，交给 Agent；后续选择变化不应改变原任务目标。任务运行期间不要手动编辑同一批对象。

## 示例

> 只修改选中的杯子：改成米白哑光陶瓷，增加细微粗糙度变化，杯沿保留干净。保留其他对象。完成后渲染一张 768 像素预览检查。

> 为选中的模型制作 1 到 48 帧弹跳循环，加落地压缩和起跳拉伸。用空物体统一控制，不改模型原始网格。回读关键帧并检查中间帧。

> 保留现有模型和材质，增加无缝背景、三点布光和相机，生成白底产品预览。灯具用 JC_ 前缀独立命名。

> 做一座高度 3 米、24 级、旋转一周的螺旋楼梯，参数集中在脚本开头。创建单独集合，不清空场景。检查踏步间距和栏杆连续性。

## MCP 工具与外部客户端

| 工具 | 功能 |
|---|---|
| `blender_attachment` | 本轮附件路径列表、限量文本、图片、带时间点的视频参考帧；PDF/模型只提供路径 |
| `blender_render_knowledge` | 仅经验库开启时提供；按需读流程、案例、结构化参数或历史成图预览；不计作已操作/检查当前场景 |
| `blender_scene` | 实时场景、版本、对象概览、选择、相机与时间轴 |
| `blender_object` | 指定对象的几何数量、变换、材质、修改器与动画概览 |
| `blender_execute` | 主线程执行 Blender Python；提供 bpy、mathutils、math、Vector、Matrix，设置 `result` 返回 JSON |
| `blender_viewport` | 截取真实交互视口，作为 MCP image 返回 |
| `blender_preview` | 相机实际渲染，临时调整尺寸，渲染后恢复原输出设置 |
| `blender_checkpoint` | 创建 `.blend` 副本，不覆盖源文件 |
| `blender_restore` | 恢复本实例创建的快照，恢复前再次保存当前状态 |

“复制外部 MCP 配置”会生成当前 Blender 实例的 `mcpServers` JSON，适合支持 stdio MCP 的客户端。Codex 配置使用 TOML 格式，可参照 `docs/架构与开发.md`。实例 ID 用于定向路由；断开后重新连接会创建新 ID，需要更新外部配置。

## 失败、取消与回退

- 执行修改前自动保存 `.blend` 副本。点“快照 / 截图”查看当前任务文件。
- “回退”恢复最近一次修改前的快照；多步任务回到开头应选择任务目录最早的修改快照。回退前也保存现状。
- “停止后续操作”取消排队的工具与 Agent 后续操作。已经进入 Blender 主线程的 Python / 渲染不能强制抢占，需等其返回或在 Blender 自身取消渲染。
- Python 出错可能已部分修改，工具明确返回 `partial_changes_possible` 与快照。不会自动回滚或重发。
- 超时视为结果未知。正在运行的命令改名为 `.running`，绝不自动重放。不要在未知状态下重复提交相同修改。
- 同一 Blender 实例一次只允许一个任务；外部 MCP 不能在插件任务运行时抢写该实例。
- “Agent 已结束”只代表本轮工具循环结束，视觉质量仍需检查。仅成功读取场景、没有修改的任务显示“已检查，未修改场景”。

## 数据、权限与边界

默认运行目录为 `%LOCALAPPDATA%/JCBlenderAgent`。含服务 discovery、随机本地令牌、每实例队列、任务日志和 `.blend` / PNG 结果。不会主动删除快照；复杂场景请定期自行整理。分析视频和测试的工作目录在项目的 `evidence` 中，不打包进插件。

服务只监听 `127.0.0.1` 的随机可用端口，每次请求验证本地令牌，拒绝网页 Origin 和异常 Host。Blender 侧不创建长期 Python 后台线程，使用主线程 timer 消费本地文件队列。

**Agent Python 具备当前用户的本机 Python 权限，不是安全沙箱**。插件偏好设置可关闭执行。快照主要保护 `.blend` 场景，不能撤销脚本对其他文件、网络或系统的任意副作用。

不会承诺任意一句话都能达到专业建模质量。参数化模型、材质节点、布光、规则动画、批量处理适合此链路；复杂角色、精细拓扑、雕刻和高质量绑定仍依赖模型能力与人工验收。长渲染或大规模 bpy 操作仍可能暂时阻塞 UI。

见 `docs/验证记录.md`、`docs/视频分析与方案.md`。发行包可用 `python build_release.py` 重建；无需安装依赖。
