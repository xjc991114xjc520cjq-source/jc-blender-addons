# JC Blender Agent 0.1.6

新增按需读取的 Blender 技能库：14 个技能、126 份资源，覆盖场景尺度、硬表面、倒角/法线、UV、PBR、烘焙、摄影灯光、渲染设置、Octane 产品流程与 QA。

- 新增 blender_skill 工具，目录、具体章节、脚本参考和长文分页均离线随包提供；CLI 与 API Agent 共用适配指令。
- 资料保留四个上游项目的来源、MIT 许可证和逐文件 SHA-256。读取不计作 Blender 实际操作或验收，外部脚本不自动执行。
- 沿用经验库开关；关闭后不暴露或读取技能。明确 Cycles/EEVEE 到 Octane 的适配边界，避免盲目增加面数、套用灯光/采样参数或重复色彩变换。
- 个人配置、API Key、登录、模型与任务历史不随包同步。A9 待审案例没有收入正式知识库。

安装：下载 JC-Blender-Agent-0.1.6.zip，在 Blender 插件设置中从磁盘安装并启用。旧版没有自动更新机制，其他设备需安装新版才能获得这些内置技能。

验证：22 项测试通过，含独立 MCP SDK、开关拒绝、路径限制、分页、资源校验及离线重定位；归档与源码一致性检查通过；Blender 5.2.2 LTS 已安装插件注册/卸载和资源读取通过。真实登录模型任务和其他设备实际安装未代测。
