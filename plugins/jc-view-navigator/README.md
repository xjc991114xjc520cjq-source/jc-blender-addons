# JC 六向视图导航 1.1.0

固定放在 Blender 右上角原生导航的位置。直接复用 Blender 自带的轴球绘制、字体、主题颜色和尺寸，不再额外排列六个中文按钮。

## 安装

1. Blender：编辑 → 偏好设置 → 插件。
2. 右上角下拉菜单 → 从磁盘安装，选择 `JC-View-Navigator-1.1.0.zip`，不用解压。
3. 启用“JC 六向视图导航”。

实际验证版本：Windows / Blender 5.2.1 LTS。插件无外部依赖，不修改 Blender 安装文件。

## 六个端点

| 颜色 | 实心端点 | 空心端点 |
| --- | --- | --- |
| 红 X | 右侧视图 | 左侧视图 |
| 绿 Y | 后视图 | 正视图 |
| 蓝 Z | 俯视图 | 仰视图 |

悬停会显示中文名称和正负方向。每次点击立即切到对应的世界坐标正交视图；重复点击同一端点保持方向。观察中心、缩放和场景对象保持不变。

轴球始终以固定的展开角度显示，确保六个入口不会在正视图中重叠，因此它用来选择视图，不随观察角度旋转。中键旋转视图仍可使用。下方保留缩放、平移、相机和透视/正交切换入口。

大小跟随 Blender：编辑 → 偏好设置 → 视图/界面中的导航控件尺寸。展开 N 侧栏时会随原生导航区避让。

## 开关与恢复

- 3D 视图 → 视图 → “JC 六向导航 / 恢复原生导航”。
- 或在插件偏好设置里关闭“用六向导航替换原生导航”。
- 禁用/卸载插件会恢复各视图原来的原生导航开关。
- 保存 .blend 时保留可在未安装本插件的电脑使用的原生导航状态。

本插件通过 Blender 的插件接口替换导航显示，不更改 Blender 程序，也不影响 Agent 插件、N 面板和模型数据。
