# JC 历史记录 1.0.0

为 Blender 5.2 编写的免费中文插件。在 3D 视图右侧常驻显示真实撤销历史，并提供命名场景快照。
已在本机 Blender 5.2.1 LTS（Windows，构建 9e2066aef7ef）进行后台功能检查和独立窗口点击检查。

## 安装

1. 打开 Blender，点击「编辑 → 偏好设置 → 插件」。
2. 点击右上角下拉菜单，选择「从磁盘安装 / Install from Disk」。
3. 选择 `JC_History_1.0.0_Blender52.zip`。不要解压。
4. 如未自动启用，搜索 `JC History`，勾选启用。
5. 鼠标放到建模窗口，按 `N`，点击右侧竖排的「JC历史」。

如果侧栏太窄，可拖动侧栏左边缘把它拉宽。插件不会自动修改你已有的窗口布局或保存中的工程。

## 日常使用

**操作历史**：列表上方是较新的操作，圆点表示当前位置。直接点击某一步就回到该状态；未作新修改前，也能点回后面的状态。上方还有「撤销」「重做」。原来的 Ctrl+Z / Ctrl+Shift+Z 保持可用。

**场景快照**：先回到物体模式，点击「保存命名快照」，输入例如「脸部完成」「配色方案一」。每个快照都是独立 `.blend` 副本，保存过程不会改变当前工程路径，也不会覆盖原工程。

**恢复快照**：点击快照旁的「恢复」，确认后先保存一份「恢复前自动备份」，再打开所选快照的工作副本。打开后点击「另存为作品」，选择你要的文件位置。即使在工作副本里直接按 Ctrl+S，也不会覆盖原来的命名快照。恢复前的状态仍在自动备份中。

**重命名**：点击快照名称右侧的铅笔图标。快照的时间、文件和内容保持不变。

**设置**：展开「历史设置与说明」可调整 Blender 的撤销步数和内存上限。插件默认不修改这些值。在插件偏好设置中可以自定义快照目录和最近快照的显示数量。

## 与参考插件的功能对应

依据 History Bookmark Pro 的公开说明分析功能，未使用、下载或反编译其源代码；本插件为独立实现。

| 参考功能 | 本插件的做法 |
| --- | --- |
| 常驻操作历史 | 把 Blender 原生真实撤销菜单内容嵌入侧栏，而非从日志猜测历史 |
| 点击回到某一步 | 使用 Blender 自己的历史按钮，状态与原生撤销一致 |
| 自动记录 / 手动记录 | 普通操作由 Blender 自动记录；重要阶段由用户手动保存快照 |
| 命名书签 | 保存命名 `.blend` 场景快照，并支持重命名 |
| 恢复书签 | 先保存恢复前备份，再打开工作副本，保护原工程和命名快照 |
| 会话后持久保存 | 快照与目录保留在本地；普通撤销栈不持久保存 |
| 清理临时文件 | 不自动清理，不设自动删除期限；可点击「快照文件夹」自行管理 |

参考文档：https://superhivemarket.com/products/history-bookmark-pro/docs

## 实际边界

- 这是类似 PS 的常驻历史面板，界面沿用 Blender 原生控件。历史较多时原生列表会自动分列，不是 PS 的单列滚动面板。可拉宽侧栏查看。
- 普通历史只限本次打开的文件会话；关闭、打开文件或新建工程后会重新开始。回退后再修改会清除后面的普通历史。保存快照不会延长普通历史寿命。
- 插件只能显示 Blender 实际记录的操作，不会把视角转动等所有界面操作都变成可撤销操作。
- 没有逐对象独立撤销、自动逐步磁盘备份、分支历史、缩略图预览。这些没有伪装成已实现的功能。
- 命名快照仅在物体模式下保存和恢复。编辑、雕刻时的普通撤销列表仍使用 Blender 原生逻辑。
- 快照保存完整工程副本，复杂工程可能较大、保存较慢。没有后台定时保存，也不自动删除旧快照。
- 快照不是外部素材打包。外部贴图、链接库、模拟缓存等仍需保留在原位置；复制快照时会重映射相对路径。
- 正常工程另存到其他路径后，会使用新的项目快照分组；旧分组文件仍保留在磁盘。恢复工作副本仍能找到原分组。
- 未保存的新工程按当前会话分组。退出前建议先保存工程；未保存工程的快照可通过它的快照文件夹再次打开。
- 快照存于所选根目录下的项目子目录，其中 `catalog.json` 是名称清单，随机编号 `.blend` 是快照，`work_` 开头的是恢复工作副本。不要在仍要使用时删除这些文件。
- 默认目录为 Blender 当前配置目录下的 `jc_history_data`，通常在 `%APPDATA%\Blender Foundation\Blender\5.2\config\jc_history_data`。以「快照文件夹」实际打开的位置为准。调整自定义目录不会搬运旧文件。
- 禁用或卸载插件不会删除快照。保留 `.blend` 文件和它引用的素材后，仍可用 Blender 直接打开。

## 验证与源码

`tests/results.json` 记录后台检查结果。测试使用单独的临时目录和默认方块场景，没有读写用户已完成的作品，也没有把插件安装到用户正在使用的 Blender 配置。

`src/jc_history/` 为可编辑源码；`build.py` 可重新生成安装包。安装包是 Blender 扩展格式，根目录直接包含 `blender_manifest.toml`。
